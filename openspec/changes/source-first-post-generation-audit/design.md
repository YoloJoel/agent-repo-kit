# Design

The Agent performs semantic source-first reading and post-fix rereading. The runtime cannot
prove cognition or correctness: audit-record validates actual declared scope/passes, stable
finding dispositions and source evidence; it stores immutable report snapshots and hashes.
Audit-status reports missing/stale/open records independently of spec and execution results.
Audit reports attach to the existing issue/decision source without becoming a second authority.
Default review uses an independent reviewer when available, otherwise explicit same-agent
separate passes. Two passes with unresolved findings checkpoint rather than force endless work.
