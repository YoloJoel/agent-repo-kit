# Complete default baseline specification handoff

## Why
A bare baseline invocation could stop at explanations and contracts, leaving no current specs.

## What Changes
Default onboarding writes/reuses source-backed current specs, records preservation decisions,
keeps ambiguous behavior separate, and checks the handoff without claiming tests executed.

## Impact
Update `src/`, `skills/`, `tests/`, `docs/` and native package metadata. No business source
changes, mandatory hosted service or secondary OpenSpec lifecycle.
