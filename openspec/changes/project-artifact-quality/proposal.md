# Project entrance and specification content quality

## Why
Mechanism checks did not ensure project-specific AGENTS, major capability coverage or
independently usable specs. Tool rules, manifest dumps and partial cross-cutting requirements
could appear successful despite weak project artifacts.

## What Changes
Source-backed project entrance rendering, explicit whole-source capability coverage, spec
self-containment/owner review and current onboarding quality status. Keep evidence links,
human assets, local-only operation and native lifecycle compatibility.

## Impact
Update `src/`, `skills/`, `tests/`, `docs/` and native version metadata to 0.2.4. No internal
project artifacts are needed or published. No mandatory daily Skill or hosted platform.
