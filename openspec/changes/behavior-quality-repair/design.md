# Design

Separate deterministic evidence checks from Agent judgments and actual model-quality trials.
Source-only discovery reads production inputs before consulting authored Spec/inventory;
its AST/lexical outputs are review candidates with explicit provider limits. Reconciliation
and input hashes expose first-time omissions and stale evidence without claiming a complete graph.

Bind complete Scenario bytes and deciding premises to acceptance cases. Freeze reader inputs,
then predictions, then source/textual adjudication in append-only readback rounds. An active-round
pointer selects the current assessment while previous rounds remain inspectable. This orders
records and preserves uncertainty; it does not sandbox readers or prove natural-language entailment.

Behavior-linked commands require fresh execution reports. The Python adapter traces assertion
lines in actual commands; JUnit and ARK JSON support external/native runners. A command exit,
selected case execution and semantic assertion adequacy are distinct. The runtime fails closed
on missing/duplicate/old reports and keeps ordinary command checks backward compatible.

Project-rule sources and explicit external snapshots join delivery currency. Unit hashes and
reverse dependency candidates preserve unrelated reviewed counts while overall unknown changes
remain pending. explain and baseline next derive views from existing authorities instead of
creating a duplicate knowledge store. Runtime remains stdlib-only and vendored; execution/trial
adapters use standalone asset boundaries. Startup deliberately avoids whole-repository scanning.

Evaluation preserves paired model/host/budget settings, an independent case denominator,
initial/audit/recheck stages and actual costs. Frozen evidence accounting is a different status
from product-quality qualification. Public synthetic consumers validate protocols; private
module M and independent held-out model trials remain required product evidence.

Compatibility: schema 1 old records remain readable but missing new evidence stays pending.
No current accepted Spec is overwritten by this active delta. Existing native tools retain
ownership of synchronization and archive. Marketplace pin changes require separate qualification.
