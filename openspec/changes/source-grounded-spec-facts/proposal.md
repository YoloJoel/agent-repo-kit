## Why

Existing source-review instructions can still produce plausible but false current guarantees.
Definitions can be mistaken for registration or validation, event-triggered work for timers,
and generic passing assertions for coverage of a different clause.

## What Changes

Require a source-fact row before each batch of new current clauses. Resolve effective literal
sets, bounds, timing, precedence and final lifecycle handlers from decisive paths. Review each
scenario's stimulus and actual observation. Complete the batch through source recheck, preserving
unknowns, defects, existing accepted authority and native workflow state.
