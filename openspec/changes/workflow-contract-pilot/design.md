# Project rules and ordinary work documents

Maintain the engineering standard and accepted decisions as authorities. Map conditional
obligations in project policy using stable rule IDs, a source, concrete artifact requirements
and optional repository path matches. Unscoped conditions need a declared assessment. Actual
matched paths independently require their artifacts. Free-form source semantics require review.

Missing intent remains visible. A scoped fix can refer to a current requirement. A production
maintenance claim identifies preserved behavior or reuses the existing preservation plan.
Reuse an accepted decision or add one through project procedures. An external design/plan is
addressed from its native wrapper. Enforce real task completion, fingerprint the content and let
the native lifecycle archive the Change. Preserve existing human documents and prior decisions.
