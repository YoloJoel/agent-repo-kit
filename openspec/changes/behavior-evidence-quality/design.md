# Design

Keep the stdlib vendored core and two installed Skills. Add independent source-derived units with triggers/conditions/outcomes, source roles, applicability dimensions, counterexamples, canonical contract values and actual assertion/check bindings. Store input hashes, immutable inventory snapshots and prior unit verification states; expose dependency closure without claiming a complete call graph.

Whole onboarding requires the new review; old inventories do not silently pass. Keep structural checks and actual command execution separate. Current specs remain current until native synchronization. An affected active candidate can use a real two-pass source audit that binds all native targets, old current specs/inventory, production sources and current assertion tests. Direct delivery, CI and close share scope conditions. Candidate bytes, tests and targets cannot be re-snapshotted as already reviewed after audit changes.

Generation remains Agent-owned: source-first discovery before spec boundaries, effective branch/use/effect tracing, per-claim attempted falsification, unknowns outside new normative promises and cross-spec reconciliation. Runtime cannot prove source reading, exhaustive discovery, assertion quality or semantic truth. Manual/external changes require real justification/evidence; no unavailable compiler/mock is automatically a pass.

Evaluation combines seeded deterministic counterexamples, native positive/negative/restored probes and isolated model tasks on raw source/upgraded assets. Real private large-project and live-host trust remain explicitly unverified. Source/wheel/installer hashes and cross-platform tests qualify distribution separately.
