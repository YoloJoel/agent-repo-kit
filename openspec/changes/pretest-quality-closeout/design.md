## Design

Reuse existing checks, fingerprints, native metadata and behavior inventory. Lightweight checks
capture a start fingerprint and candidate diff, run actual commands, then reject changed inputs
within the same run. Required-command availability resolves its declared cwd and executable.

Parse Depends-On with the same complete REQ identity matcher. A verified file-native change
returns PENDING/native-archive-required with CLI exit 2 and leaves its files unchanged. Legacy
metadata changes retain their archive transaction. Native synchronization/archive stays native.

Find assertion snippets in the complete original test file and require every selected line of
the actual contiguous statement. Python token positions and bounded C-family lexical guards
exclude comments and literals, including docstrings/text blocks/raw strings. This is a location
guard; the Agent must still review stimulus, observation and wrong-behavior detection, and native
checks must actually run.

## Qualification

Keep old failing reproductions and rerun their unmodified inputs against the repair. Execute
source, installed-wheel and vendored consumer checks and C/C++/Java/Python pass/fail/pass probes.
Run ordinary isolated full onboarding over fixed source-only and existing-governance snapshots,
then independently compare actual products to source and audit preserved inputs. Keep unavailable
implementations, partial source review and execution gaps explicit. Preserve private inputs and
outputs privately; public evidence contains only generic/sanitized facts and fingerprints.
