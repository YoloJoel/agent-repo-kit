## 已确认并修复

| 范围 | 原始反例 | 修复后的实际要求 |
| --- | --- | --- |
| 轻量检查 | required 命令改写源文件或本轮 note 后仍可 PASS | 同一轮绑定输入指纹、候选内容/执行位及声明，改变即 FAIL，保留真实命令日志 |

## 适用边界

位置校验不是完整语言解析器，也不证明测试发现、路径可达或错误行为一定被断言捕获。
已复现的 JavaScript 正则字面量定位限制仍需人工/Agent 源码审阅；原生测试执行不能由片段匹配替代。
私有参考仓中不在本次源码里的历史实现、缺少的断言和外部依赖保留实际 PENDING，
不通过删除覆盖分母、降低 Verification 或改写既有承诺清空缺口。

用户内部大仓及其 DeepSeek 运行器的实测仍须在原环境完成。其它宿主的信任、完整模型会话 Stop、
未实现的 OpenCode 生命周期插件保持既有支持边界；本轮不依赖这些能力完成现状 Spec 接入。
