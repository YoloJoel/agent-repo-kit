显式映射必须对应必需的 delivery 检查，不能用 ready-only/optional 或不同 Verification 类型降级。
运行时读取的 Markdown 等文档可通过 behavior_paths 声明。空/二进制输入采用真实内容哈希引用，
保留调用方契约与语义缺口。静态引用、格式通过和哈希都不冒充业务正确性证明。
