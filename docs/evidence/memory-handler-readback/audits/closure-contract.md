## Timing and failure

Delivery runs synchronously inside the triggering call. A successful return from the target's handle method advances the loop for *any* return value. A partial failure conveys neither a count nor an automatic resumption position. Threshold evaluation, truth testing and callbacks can run caller code. Effects performed by that code are its own, including changes to target, record or buffer. This contract does not model arbitrary custom emitter/filter overrides as though they had standard behavior.

The constructor and setTarget store a destination without invoking its truth hook (logging/handlers.py:L1392-L1396, logging/handlers.py:L1405-L1410). In flush, `if self.target` runs before the loop even on an empty buffer (logging/handlers.py:L1420-L1424). If the hook records an event and raises, the same exception escapes; the event remains, no delivery starts and the sender never reaches clear. A threshold-triggering entry was appended before this point (logging/handlers.py:L1348-L1350). Unless the hook changes the target or buffer, both survive an explicit or automatic flush failure. A subsequent flush tests the current target anew and starts at the front. Close detaches the target and runs inherited cleanup before the exception reaches its caller (logging/handlers.py:L1431-L1437, logging/handlers.py:L1367-L1370, logging/__init__.py:L1054-L1058).

## Compatibility and promotion

Preserve these observable rules at this frozen revision. In particular, the close docstring's phrase “lose the buffer” cannot establish unconditional discard against the actual dynamic call sequence. Internal locking, private cleanup, global shutdown, garbage collection, global logging configuration, unrelated handlers and target-owned side effects beyond the described call/return/raise boundary do not add promises. The submitted source case map predates the draft. Source analysis supports this current contract. No existing test files or confirmed commands were supplied for verification, and no upstream suite or runtime attestation is claimed.
