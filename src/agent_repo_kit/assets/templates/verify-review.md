# Verification review

<!-- ARK:FILL -->

## Scope and revision
Record Change/work identity, source revision and workspace differences.

## Coverage
Map accepted/preserved and changed requirements to meaningful tests or external evidence.

## Consistency review
Explain implementation versus Spec/Design, compatibility, source evidence and decisions.

## Executed checks
Reference generated run IDs and actual command/exit/result artifacts. NOT_RUN is not PASS.

## Risks and next steps
State unverified conditions, gaps, external gates and actual next step.

## Conclusion
Distinguish specification-stage, implementation delivery and post-archive synchronization.
