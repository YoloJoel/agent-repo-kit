# Control hub source-fact fixture

This bounded C project exercises effective registration, dispatch, message fields, configuration,
ordered rules, event-triggered windows and signal-handler installation. Declared constants and
validators differ from effective paths so source-derived specifications must describe observed
conditions precisely. The original tests cover selected paths.

Run `make test` with a C99 compiler, make and Python 3. To execute the source observations,
run `python tools/qualify_source_facts.py --output <directory>` from the toolkit repository.
The probe checks native capacity rejection and alters a rule outcome in a disposable copy
to determine whether the original assertions notice it.

For a model task, copy the C sources, Makefile and original tests into an isolated repository,
install the Skill version being evaluated and use an ordinary existing-repository onboarding
request. Keep this README, the probe's expected observations and evaluation results outside
the generation input. Record exact input/resource hashes and preserve original source/tests.
